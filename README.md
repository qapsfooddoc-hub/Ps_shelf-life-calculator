# เครื่องคำนวณอายุสินค้าคงเหลือ (Shelf-Life Calculator)

เว็บแอปเครื่องมือคำนวณ % อายุสินค้าคงเหลือจากวันที่ผลิตและวันหมดอายุ เทียบกับเกณฑ์ขั้นต่ำ 75%
เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่มีการเชื่อมต่อฐานข้อมูลหรือส่งข้อมูลใด ๆ ออกจากเครื่อง
คำนวณทั้งหมดในเบราว์เซอร์ของผู้ใช้ ปฏิทินเลือกวันที่เป็นปี ค.ศ. (ตามมาตรฐานของเบราว์เซอร์)

## วิธีนำขึ้นออนไลน์ด้วย Git + Vercel

ไม่จำเป็นต้องมีฐานข้อมูลหรือ build step ใด ๆ เพราะเป็น static HTML ไฟล์เดียว ทำตามขั้นตอนนี้ได้เลย:

### 1. เตรียม repository บน GitHub

1. สร้าง repository ใหม่บน GitHub (เช่นชื่อ `shelf-life-calculator`)
2. ในเครื่องคุณ เปิด terminal ไปยังโฟลเดอร์ที่มีไฟล์ `index.html` นี้ แล้วรัน:

   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial commit: shelf-life calculator"
   git branch -M main
   git remote add origin https://github.com/<ชื่อบัญชีของคุณ>/shelf-life-calculator.git
   git push -u origin main
   ```

### 2. เชื่อมกับ Vercel

1. ไปที่ [vercel.com](https://vercel.com) แล้วเข้าสู่ระบบด้วยบัญชี GitHub เดียวกัน
2. กด **Add New… → Project**
3. เลือก repository `shelf-life-calculator` ที่เพิ่ง push ขึ้นไป
4. หน้าตั้งค่า Vercel จะตรวจพบว่าเป็น static site โดยอัตโนมัติ (Framework Preset: **Other**) — ไม่ต้องตั้งค่า Build Command หรือ Output Directory ใด ๆ ปล่อยว่างไว้ได้เลย
5. กด **Deploy**

ภายในไม่ถึงนาที Vercel จะให้ลิงก์ เช่น `https://shelf-life-calculator.vercel.app` ที่เปิดใช้งานได้ทันที

### 3. อัปเดตในอนาคต

ทุกครั้งที่แก้ไข `index.html` แล้ว push ขึ้น branch `main` (`git add . && git commit -m "..." && git push`)
Vercel จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ ไม่ต้องตั้งค่าเพิ่มเติม

## หมายเหตุเรื่องความปลอดภัยของข้อมูล

- ไม่มีการบันทึกข้อมูลลงฐานข้อมูลหรือเซิร์ฟเวอร์ใด ๆ
- ไม่มีการเรียก API ภายนอก ยกเว้นการโหลดฟอนต์จาก Google Fonts (ใช้เพื่อความสวยงามของตัวอักษรเท่านั้น)
- ข้อมูลวันที่ที่กรอกจะหายไปทันทีที่ปิดหรือรีเฟรชหน้าเว็บ

## สูตรคำนวณ (อ้างอิงจากตัวอย่าง)

- **อายุสินค้าทั้งหมด** = (วันหมดอายุ − วันที่ผลิต) + 1 วัน
- **จำนวนวันที่เหลือ** = (วันหมดอายุ − วันที่ตรวจสอบ) + 1 วัน
- **% อายุสินค้าคงเหลือ** = จำนวนวันที่เหลือ ÷ อายุสินค้าทั้งหมด × 100
- หากคำนวณได้ **น้อยกว่า 75%** ระบบจะแสดงแบนเนอร์แจ้งเตือนสีแดงและไฮไลต์ตัวเลข % เป็นสีแดงทันที
